# Homepage favourites

Running list of layout + canvas combinations Defne liked while exploring the redesign. Layouts are the letters in the switcher; canvas settings are the render / motion / hover rows plus a colour swatch.

## Favourite combinations

| Layout | Colour | Render | Motion | Hover |
|---|---|---|---|---|
| D / F | Amber `#F2B26B` | tiles | breathe | rainbow |
| D / F | Sky `#7FA8F5` | tiles | breathe | rainbow |
| any | any | glyphs | trickle | rainbow |
| any | any (“really pretty”) | glyphs | trickle | mono |
| D / F | any | tiles | geometric | mono / rainbow |
| D / F (“loki”) | any | tiles | lightning | mono / rainbow |
| any | Sky especially | tiles | any | rainbow |
| any | any | cipher | brush | mono / rainbow |

## Likes
- Tiles is the best render. Tiles + breathe + rainbow must stay exactly as it is.
- Lightning, but only on tiles.
- Brush (the surging colour after the stroke), geometric (the pulse), cipher. Cipher + brush especially.
- Rainbow hover with every colour, especially blue.

## Rejected (removed)
Layouts A, B, C, E, G, H, I, J, K, L (only D and F kept). Lamp, glass, ascii, mosaic, butterflies, fireworks, pour, spider. Any animation that runs without the cursor. The big oblong halo behind text blocks in G (plain text shadow with a wide blur instead).
