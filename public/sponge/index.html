How to Use It

Icons: Open a PNG in Preview, select all, and copy. Select your app or folder in Finder, choose Get Info, click the small icon in the top-left corner, and paste. To undo, select that small icon and press Delete. Some protected system icons cannot be changed, and app updates can reset custom icons.

Wallpapers: Add your image in System Settings → Wallpaper. The kit also includes a dynamic HEIC with morning, day, sunset, and night. Select Dynamic where supported. The scenic and Halloween versions are separate static wallpapers.

Wallpapers are 3840 × 2160 exports, upscaled from generated originals. App icons include PNG and ICNS files. Download installation notes · Download dynamic wallpaper
