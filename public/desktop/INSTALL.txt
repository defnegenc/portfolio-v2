INSTALL ICONS ON MAC
Open a PNG in Preview, select all, then copy. In Finder select the app or folder and choose File > Get Info. Click the small icon at the top left and paste. Some system apps and the Dock Trash are protected and may not accept custom icons. Updates can reset app icons. These files do not install automatically.
To restore an icon, select the small icon in Get Info and press Delete.

WALLPAPERS
Add an image in System Settings > Wallpaper.
The dynamic HEIC contains morning (6 AM), day (10 AM), sunset (5 PM), and night (8 PM) frames. Choose Dynamic if available. New scenic wallpapers are separate static alternatives.
